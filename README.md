# CodeIgniter 4 POS System

A simple multi-page Point of Sale website created using CodeIgniter 4. This project demonstrates the MVC structure through routes, controllers, views, shared layouts, and static data arrays.

## Features

- Home page
- About page
- Customers page with five static customer records
- Users page with five static user records
- Shared navigation and footer
- Responsive Bootstrap design
- Forest and Sage color palette

## Routes

| URL | Page |
|---|---|
| `/` | Home |
| `/about` | About |
| `/customers` | Customers |
| `/users` | Users |

## Technologies Used

- PHP 8.3
- CodeIgniter 4.7.4
- Bootstrap 5.3.8
- MAMP
- Git

## Local Setup

1. Place the project inside the MAMP `htdocs` directory.
2. Run `composer install`.
3. Set the MAMP document root to the project's `public` folder.
4. Start the MAMP Apache server.
5. Open `http://localhost:8888/`.
